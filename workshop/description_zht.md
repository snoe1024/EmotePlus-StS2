[b]客戶端 Mod：不再影響遊戲進程！[/b]

[b]大幅擴充了表情功能！[/b]
在多人模式中，按住 V 鍵並操作滑鼠，就可以在畫面上顯示表情。你知道嗎？
不過，原版的表情無論誰使用外觀都一樣，而且直接顯示在發送者的螢幕座標上，非常不方便。

本 Mod 會用使用者角色的顏色為表情描邊，並[b]精確顯示在 UI 畫面上的對應位置[/b]。
此外還導入了分頁，讓你可以從更多種類的表情中選擇使用！

[b]透過角色顏色一眼分辨[/b]
表情的描邊會變成使用該表情的玩家的角色顏色。

[b]依畫面內容顯示在合適的位置[/b]
表情不是依螢幕座標顯示，而是精確顯示在「該玩家目前開啟的畫面中的對應位置」。
[list]
[*]地圖等捲動畫面：顯示在 UI 上的對應位置。即使捲動，表情也會固定在 UI 上的位置。
[*]對方開啟了其他畫面時：顯示在通往該畫面的按鈕的位置。
[*]卡牌收藏等處的卡牌詳細資訊：會以便於依序追溯「為了查看這張卡牌按過哪些按鈕」的方式顯示。
[/list]

[b]分頁式表情輪盤[/b]
由於表情越來越多，輪盤的 8 個格子已經不夠用，所以將輪盤改成了分頁式。
[list]
[*]開啟輪盤期間，可以用滑鼠滾輪切換頁面。可在設定中反轉方向。
[*]輪盤中央會顯示目前頁碼，例如「1/3」。
[*]在保留表情連發功能的同時，現在也可以在按下表情鍵後選擇不發送任何表情。
[/list]

[b]選擇要使用的表情[/b]
今後表情還會繼續增加，因此可以在 Mod 設定中逐一切換顯示/隱藏。
此外，現在還可以自由設定輪盤上表情的排列順序！
自由調整要顯示的表情，打造屬於你的表情牌組吧！

[b]其他參與者未安裝本 Mod 時[/b]
房主安裝了 RitsuLib 時，本 Mod 的安裝者之間會共享額外表情及其位置。
未安裝本 Mod 的玩家會將自己沒有的額外表情看到為「?」。
未安裝本 Mod 的玩家發出的表情會像原版一樣顯示在螢幕座標上。
房主沒有 RitsuLib 時，效果等同於其他玩家均未安裝本 Mod。

[b]分支支援[/b]
同時支援預設分支和公開測試(Public Beta)分支。

[b]必要 Mod[/b]
BaseLib、RitsuLib（作為工作坊相依項目自動安裝）。
[b]為使多人遊戲中不再需要所有人安裝本 Mod，新增了 RitsuLib 相依項目。[/b]
更新 Mod 後如果無法正常載入，請檢查是否安裝了 RitsuLib。
